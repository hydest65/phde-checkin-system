## 当前已知限制

### 1. 浏览器自动定位

当前测试地址使用的是：

```text
http://101.43.48.229:3000
```

这是 `HTTP + 公网 IP` 访问方式。  
多数浏览器对自动定位有安全限制，因此当前 Web 版可能出现：

- 页面和地图模块能显示
- 但实时定位会失败

这不代表签到主流程故障。当前测试阶段可继续使用：

- 手动选择地点
- 正常提交签到

### 2. 还没有正式域名与 HTTPS

当前适合：

- 内部测试
- 小范围试用
- 流程验证

当前还不适合：

- 正式公网长期使用
- 依赖 HTTPS 的浏览器定位正式体验
- 微信小程序正式接入

## 正式上线前建议

建议按这个顺序推进：

1. 注册正式域名
2. 完成备案
3. 配置 Nginx
4. 配置 HTTPS
5. 将 Web 访问地址切换到正式域名
6. 条件允许时接入 Postgres

## 数据安全建议

当前文件存储适合测试阶段。
