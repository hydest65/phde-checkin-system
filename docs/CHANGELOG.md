# PHDE签到系统变更日志

本文件用于记录每次版本更新。每次完成代码或功能变化后，都应同步更新本文档，并根据影响范围更新 `PRD.md`、`TECHNICAL_PLAN.md` 和 `WEB_TEST_DEPLOY.md`。

## 版本记录

### 0.1.5 - 2026-04-27

- 修改：版本收尾流程改为先比较本地与 GitHub 哪一端更新，再把较新的版本同步到另一端。
- 修改：如果本地和 GitHub 两边都有新改动，版本收尾时先停止自动同步并提示需要确认合并方向。
- 文档：更新 `docs/DOC_UPDATE_RULES.md` 中的 GitHub 双向同步规则。
- 修改：将 `package.json` 版本号更新为 `0.1.5`。
- 验证：运行文档检查。

### 0.1.4 - 2026-04-27

- 新增：产品文档 `docs/PRD.md` 和技术方案 `docs/TECHNICAL_PLAN.md` 需要先输入管理密码后才能访问。
- 新增：后台登录统一由服务端校验并同步登录凭证，直接访问受保护文档时服务器也会校验权限。
- 修改：管理入口说明补充文档访问权限范围。
- 修改：将 `package.json` 版本号更新为 `0.1.4`。
- 验证：运行 JavaScript 语法检查和文档检查。

### 0.1.3 - 2026-04-27

- 修改：员工输入姓名后不再自动带出工号或手机号。
- 修改：首次登记仍需填写姓名、工号和手机号；再次签到或修改时必须手动输入正确工号。
- 修复：姓名已登记但提交了不同工号时，前端和后端都会拒绝，避免同一员工被错误创建为新档案。
- 修改：将 `package.json` 版本号更新为 `0.1.3`。
- 验证：运行 JavaScript 语法检查和文档检查。

### 0.1.2 - 2026-04-27

- 修复：自动定位成功但逆地理解析尚未返回时，今日签到状态只显示“当前位置附近”的问题。
- 修改：签到提交前会等待一次地址解析；若地图服务没有返回城市和道路，则使用手动地点生成“城市：当前城市，大概位置：xxx附近”的完整展示文本。
- 修改：将 `package.json` 版本号更新为 `0.1.2`。
- 验证：运行 JavaScript 语法检查。

### 0.1.1 - 2026-04-27

- 新增：建立 GitHub 云端仓库同步流程，仓库地址为 `https://github.com/hydest65/phde-checkin-system`。
- 新增：补充 `README.md` 和 `.gitignore`，方便云端查看和避免上传本地测试数据。
- 新增：建立文档自动更新规则 `docs/DOC_UPDATE_RULES.md` 和文档检查脚本 `scripts/check-docs.js`。
- 修改：将 `package.json` 版本号更新为 `0.1.1`。
- 文档：同步补充技术方案和 Web 测试部署说明中的 GitHub 同步、版本收尾和文档检查规则。
- 验证：运行文档检查和 JavaScript 语法检查，均已通过。

### 0.1.0 - 初始 Web 原型

- 建立员工上班签到页面。
- 支持员工首次自助登记并签到。
- 支持同一员工当天一次签到修改机会。
- 支持今日签到状态展示。
- 支持管理员登录、单日记录、月度统计、员工名单导入和 Excel 兼容导出。
- 使用轻量 Node.js 服务保存数据到 `data/phde-state.json`。
- 项目目录和脚本名改为英文，降低 Windows 中文路径和终端编码风险。
