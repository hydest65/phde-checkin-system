# PHDE签到系统产品需求文档

## 1. 项目定位

PHDE签到系统用于员工上班签到。第一版从 Web 端开始，后续可复用同一套数据接口扩展到微信小程序。系统强调简洁、现代、高端，视觉延展 Morimatsu 官网和 Logo 标准，避免复杂考勤系统的臃肿感。

## 2. 第一版目标

- 员工可用手机或电脑打开网页完成上班签到。
- 员工信息初始可以为空，员工首次签到时自助填写资料并自动建立档案。
- 每位员工每天首次签到后允许修改一次签到信息，修改后不能再次修改。
- 所有人可查看今日所有已登记员工的签到状态。
- 管理员可用简单管理密码进入后台。
- 管理员可导入员工名单、查看记录、导出 Excel 兼容文件。
- 先独立运行，不接入 HR、OA、企业微信或门禁系统。

## 3. 用户角色

### 员工

- 输入姓名、工号、手机号。
- 选择手动地点。
- 授权或拒绝设备定位。
- 查看实时定位地图和中文化大概地址。
- 查看签到成功信息。
- 查看今日所有已登记员工的签到状态。
- 展开“签到动态”查看最近往日员工签到情况。

### 管理员

- 输入管理密码进入后台。
- 查看今日概览。
- 按日期查看单日签到明细。
- 查看月度统计。
- 导入或导出员工名单。
- 导出单日明细、月度明细和月度统计。
- 在后台查看产品文档和技术方案。

## 4. 员工端功能

### 4.1 首次登记并签到

员工首次使用时填写：

- 姓名
- 工号
- 手机号
- 手动地点
- 自动定位

如果工号不存在：

- 系统自动创建员工档案。
- 员工档案备注为“员工自助登记”。
- 同时写入当天签到记录。

如果工号已存在：

- 系统校验姓名是否与工号匹配。
- 姓名匹配时允许签到，并更新手机号。
- 姓名不匹配时提示“工号与姓名不匹配。”

手动地点选项：

- 光启园办公室
- 惠南办公室
- 祝桥苑办公室
- 常熟工厂
- 海外出差
- 国内出差
- 居家办公

规则：

- 不判断迟到。
- 不限制签到地点。
- 每天首次签到后有一次修改机会。
- 员工填写姓名和工号时，页面通过签到前确认提示实时说明本次操作状态和修改机会，帮助员工在提交前确认。
- 当天第二次提交同一工号和姓名时，视为修改当天签到，覆盖签到时间、手动地点和自动定位地址。
- 当天修改一次后不能再次修改，提示“今日签到已修改过，不能再次修改。”
- 首次签到成功后提示“还有一次修改签到机会。”
- 修改签到成功后提示“这是最后一次修改签到机会。”
- 定位拒绝授权时允许签到，自动定位显示“未授权”。
- 定位失败时显示“自动定位异常”。
- 页面和导出中不展示经纬度，只展示中文化大概地址。

### 4.2 今日签到状态

所有员工都能看到：

- 姓名
- 工号
- 手机号
- 已签到或未签到
- 签到时间
- 手动地点
- 自动定位中文大概地址
- 修改机会状态，如“可修改 1 次”或“修改已用完”

排序：

- 已签到员工按签到时间倒序排列。
- 未签到员工放在后面。

统计：

- 显示“今日已签到 X / 总人数 Y”。

### 4.3 签到动态

首页今日状态下方提供可折叠“签到动态”模块：

- 默认收起，避免干扰员工当天签到。
- 展开后显示最近 30 条往日签到记录。
- 每条记录显示员工姓名、日期、时间、手动地点和自动定位中文大概地址。
- 今日签到仍保留在“今日状态”中，签到动态只展示往日记录。

## 5. 管理后台功能

### 5.1 登录

第一版使用简单管理密码：`PHDE2026`。

后续版本再支持：

- 修改管理密码
- 管理员账号
- 分角色权限

### 5.2 今日概览

显示：

- 今日已签到人数
- 员工总数
- 本月签到人次

### 5.3 单日记录

管理员可按日期查看：

- 姓名
- 工号
- 签到时间
- 手动地点
- 自动定位中文大概地址
- 修改机会状态

### 5.4 月度统计

第一版重点支持月度统计表：

- 姓名
- 工号
- 本月签到天数
- 最近签到时间

### 5.5 员工名单管理

第一版支持两种建档方式：

- 员工首次签到时自助登记。
- 管理员通过表格文本批量导入。

导入表头：

- 姓名
- 工号
- 手机号
- 邮箱
- 备注

重复工号处理：

- 提示管理员选择覆盖或跳过。

### 5.6 Excel 导出

支持：

- 单日签到明细
- 月度签到明细
- 月度签到统计
- 员工名单

文件名规则：

- `PHDE签到系统-签到记录-YYYY-MM-DD.xls`
- `PHDE签到系统-月度签到记录-YYYY-MM.xls`
- `PHDE签到系统-月度签到统计-YYYY-MM.xls`
- `PHDE签到系统-员工名单.xls`

### 5.7 产品文档与技术方案

管理员登录后台后可查看：

- 产品文档 `docs/PRD.md`
- 技术方案 `docs/TECHNICAL_PLAN.md`

文档不对未登录用户公开，必须通过后台登录后的受保护接口读取。

## 7. UI 风格

品牌依据：

- 官网：https://www.morimatsu-lifesciences.com/zh-cn/
- Logo 标准色：`RGB 0, 140, 211`
- 辅助深灰：`RGB 89, 87, 87`

视觉关键词：

- 白底
- Morimatsu 蓝
- 深灰文字
- 低饱和蓝白渐变
- 浅米色高光
- 浅蓝灰主色与柔和浅蓝卡片背景
- 洁净室实验人员高清背景
- Spatial UI / VisionOS 式空间界面
- 半透明毛玻璃面板
- 轻投影层级
- 现代无衬线字体
- 克制专业
- 高端制造
- 数字化
- 手机优先
- 支持深色模式

页面结构：

- 顶部放完整 Logo 视觉和系统名称。
- 顶部 Logo 使用透明横版 Morimatsu 视觉，避免独立白色矩形底色或厚重边框。
- 员工端打开后优先看到登记签到表单，表单中包含签到前确认提示；首页标题区应保持紧凑，不再额外显示 `PHDE` 眼标。
- 今日状态放在签到区下方或右侧。
- 移动端优先使用浮动玻璃导航、简洁确认提示和留白充足的清晰输入区域，避免横向任务栏式组件。
- 主要对话框、卡片、输入框和按钮保持统一大圆角、半透明边框、背景模糊和细微投影，形成空间感轻拟物 SaaS 质感。
- 标题使用粗体居中样式但控制字号，数字指标保留强调但不过度放大，正文保持常规字号与中灰色。
- 卡片、按钮和数据模块支持轻微入场动画与悬浮反馈，同时尊重系统减少动态效果设置。
- Figma 可编辑稿可作为 UI 调整来源，确认后同步回 Web 原型。
- 后台使用简洁数据卡片和表格。

## 8. 后续微信小程序方向

小程序第一版建议保留高频功能：

- 员工首次登记并上班签到
- 查看今日状态
- 定位授权
- 管理员查看简单概览

小程序与 Web 共用：

- 员工表
- 签到记录表
- 地点配置
- 导出服务
- 管理密码或管理员身份接口
